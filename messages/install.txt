Modern Themes 已安装。

本包包含两套完整主题：

- VS Code Dark Modern Me —— 复刻 VS Code Dark Modern 的 UI 主题与代码配色，并带
  侧栏文件图标主题（file_icon_theme: "VS Code Dark Modern Me"）。
- Monokai Me —— 经典 Monokai 配色 + 增强规则（Markdown / LaTeX / LSP 语义 token），
  搭配现代暖色 UI 主题。

启用方式（二选一）：

1. Preferences → Package Settings → Modern Themes
2. Command Palette：Modern Themes: Select ...

执行任一 "Select ... UI Theme" 命令会自动启用侧栏文件图标；手动配置主题时请同时在
Preferences 中设置 "file_icon_theme": "VS Code Dark Modern Me"。

LSP 语义高亮为可选功能：安装 LSP 包并在 LSP.sublime-settings 中设置
"semantic_highlighting": true 后，函数/类型/参数等 token 会按语义着色。
未安装 LSP 时，Sublime 原生 syntax scopes 的高亮完整可用。

可选的 LSP UI 样式：安装 LSP 后，可运行 `Modern Themes: Apply VS Code Dark Modern Me
LSP UI Style` 或 `Modern Themes: Apply Monokai Me LSP UI Style`。命令会同时安装 popup 与
Diagnostics Annotation 样式，并分别备份 `Packages/LSP/popups.css` 和
`Packages/LSP/annotations.css`；使用 `Modern Themes: Restore Previous LSP UI Style` 可恢复。
应用或恢复后请重启 Sublime Text。

如需显示右侧 Diagnostics Annotation，请自行在 LSP.sublime-settings 中设置
"show_diagnostics_annotations_severity_level": 2 和 "show_code_actions": "bulb"。
